# Qalbify Quran-Emotion Dataset

This dataset links Quranic verses to emotional themes for AI-powered emotional wellness applications.

## Structure
Each file corresponds to one emotion: fear, anxiety, depression, happiness.

### JSON Format
{
  "ayah_arabic": "...",
  "translation": "...",
  "emotion": "...",
  "theme_tags": ["..."],
  "tafsir_summary": "...",
  "context": "Surah ..."
}

### Source
All translations are from **Sahih International**, with tafsir summaries adapted from classical commentaries (Ibn Kathir, Ma’arif al-Qur’an).

Use for research, app development, or emotion-based Quranic recommendation systems.
